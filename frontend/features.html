Features

Vyorra turns the question papers you already own into a living question bank — then generates print-ready papers, runs proctored online tests and returns student analytics the same evening.

Build the question bank once

Most institutes already own a decade of question papers — scattered across PDFs, Word files, printouts and handwritten sets. Vyorra's importer reads those files and pulls out questions, options, answers, solutions and diagrams into a review pool. Faculty approve or correct each item before it enters the bank, so nothing enters your library unchecked.

  • Import from anything: PDF, DOCX, scanned images and photographed handwritten sets.
  • Maths and diagrams survive: equations are preserved as real formulas, figures are cropped and attached to the question they belong to.
  • Tagged automatically: subject, chapter, topic, difficulty and question type, all editable.
  • Duplicate detection: the same question imported twice is flagged instead of silently duplicated.

Generate print-ready papers

Pick a chapter mix, a difficulty spread and a total mark count, and Vyorra assembles the paper. Output is a clean DOCX or PDF with your institute's letterhead, instructions block and marking scheme — ready for the photocopier without reformatting.

Blueprint control

Set how many marks come from each chapter and each difficulty band. The generator respects the blueprint instead of picking at random.

Multiple sets

Generate Set A / Set B / Set C with shuffled order and equivalent difficulty to cut copying in a crowded hall.

Answer keys

Every paper ships with a matching key and solution sheet, generated at the same moment.

Run proctored online tests

The same bank powers online tests. Attempts are bound to a device and roll number, tab-switching is logged and repeat attempts are blocked. Flags go to a teacher review queue — the system never punishes a student automatically.

Attendance and analytics

Attendance is recorded from the institute panel or the Android app, and results roll up into per-student, per-batch and per-chapter views. You can see which chapter a batch is weakest in before the next class, not after the term test.

  • Student-level score history across every test taken.
  • Chapter-wise weakness reports for a whole batch.
  • Attendance registers exportable for parent communication.
  • Faculty activity view — who added questions, who set papers.

Android app for institutes

The institute app carries the same dashboard, question library, attendance and results as the web panel. The student portal installs as an app on any phone, so students do not need the Play Store to take a test.
